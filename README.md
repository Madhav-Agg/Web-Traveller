# Internet Time Machine

An interactive museum of the web, rebuilt era by era in pure HTML and CSS.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```

## Tech Stack

- TanStack Start
- TypeScript
- React
- Tailwind CSS
